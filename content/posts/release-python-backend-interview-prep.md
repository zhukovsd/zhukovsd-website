# 🐍 Релиз методички для подготовки Python Backend собеседованиям

https://zhukovsd.github.io/python-backend-interview-prep/

Суть - в сообществе накоплена коллекция из записей технических собесов (в сумме уже 300+, из них 60+ на Python). Для записей сделаны таймкоды.

Методичка содержит себе вопросы только из реальных собеседований. Для каждой категории, и индивидуального вопроса автоматически рассчитывается % популярности.


Например, вопросы по Python Core задают на 69% собесов, а по Git - на 16%.

### Что внутри

- [500 вопросов](https://zhukovsd.github.io/python-backend-interview-prep/questions/) по теории с процентом популярности и ответами
- [63 задачи](https://zhukovsd.github.io/python-backend-interview-prep/livecoding/) на лайвкодинг в 3 категориях
- [82 вопроса](https://zhukovsd.github.io/python-backend-interview-prep/thought-exercises/) на подумать в 9 категориях — вопросы на ход мыслей без единственно верного ответа

### Моки

Напоминаю, что в сообществе есть чат для [моков](https://t.me/+8YGzqvJOndg1Yjky), моки проходят в открытом виде, можно подключаться и слушать. Каждый месяц проводим 100+ часов моков.

Полный доступ к инфраструктуре подготовки к собесам (коллекции собесов, резюме, легенд, безлимитные моки) возможен в рамках [менторства по трудоустройству](https://zhukovsd.it/services/employment-mentorship/).
