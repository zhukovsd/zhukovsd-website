# 👩‍💻 Рефакторинг Java роадмапа

https://zhukovsd.github.io/java-backend-learning-course/

### Суть изменений

- Проект "погода" удалён
- Проект "планировщик задач" теперь является обязательным к написанию перед подготовкой к поиску работы. В проект добавлен новый сервис интеграция с AI/LLM

Роадмап появился в конце 2022 года, с тех пор требования к Middle разработчикам не стояли на месте, Кафка и опыт с микросервисами стали более востребованы. Работа над легендой и прохождение собеседований, соответственно, теперь включают в себя эти разделы знаний, освоить которые проще, имея практический опыт.

---

Для начала подготовки к трудоустройству, я требую 6 реализованных проектов, поэтому последний (ранее - седьмой), в большинстве случаев пропускают. Седьмой проект, планировщик задач - микросервисный проект с Kafka, JWT.

Поэтому, я решил сделать данный проект обязательным, не удлиняя прохождение роадмапа через растущее количество проектов.

---

Основной задачей проекта "погода" была работа с внешней интеграцией - погодным API.

Вместо неё в [ТЗ планировщика задач](https://zhukovsd.github.io/java-backend-learning-course/projects/task-tracker/) добавлена интеграция с LLM/AI:

> Составление отчета по задачам через LLM.
>
> Необходимо написать отдельный сервис, который будет интегрироваться с LLM по API и делать суммаризацию - генерировать отчет по итогам дня, сделанным и несделанным задачам.
>
> Сервис принимает сообщение через кафку с данными по задачам за определенный период, полученный результат он также отправляет в кафку инициирующему сервису, реализуя паттерн RPC.

### Вопросы

- **(Вопрос)** Если я начал(с) писать "погоду", стоит за заканчивать? Где теперь найти ТЗ?
  - **(Ответ)** Заканчивать стоит. ТЗ можно найти на гитхабе роадмапа, в истории коммитов - [ссылка](https://github.com/zhukovsd/java-backend-learning-course/blob/f9673b8e34132ca127b1f80981764bb31fc955f7/content/projects/weather-viewer.md)
- **(Вопрос)** Если я уже написал(а) проект "погода", какой мне писать дальше?
  - **(Ответ)** Облачное хранилище или планировщик задач
- **(Вопрос)** Если я уже написал(а) проекты до облачного хранилища включительно, обязательно ли писать планировщик задач?
  - **(Ответ)** Нет

Коллекция реализаций и ревью останется доступной - https://zhukovsd.github.io/java-backend-learning-course/finished-projects/weather-viewer/

### Мелкие правки

- В [ТЗ](https://zhukovsd.github.io/java-backend-learning-course/projects/cloud-file-storage/) облачного хранилище добавлена ремарка про то, что можно или писать работу с сессией и куками вручную, или воспользоваться Spring Security
